其实自小学起，我就在写小说了。

那时在一位非常要好的同学“怂恿”下，我开通了新浪博客，在上面写过一部没有结尾的小说。篇幅不长，只有寥寥几个章节。后来再登录博客，已经找不到当时写的东西了。我一直觉得，我爸的老电脑里或许还留着一些小学时的作品，只是始终没去翻，大概还是不太好意思面对这些“黑历史”。

写到这里，我又有些忍不住，于是跑去打开了那台老电脑。还真让我找到了。虽然留下来的只是个残本，但看着那些由我亲手敲出来的文字，我还是发自内心地笑了。原来以前的我这么尬吗？

我常常在想，那些作家为什么总有那么多东西可以写。我好像从头到尾只会说大白话，有时候甚至连大白话都不能随心所欲地表达清楚。现在写下这些，可能最后也只有我自己会看到，等于又亲手给未来的自己准备了一份“黑历史”。

真是闲的。

不过，这次究竟要写一个什么样的故事，我心里其实也没有数。大概还是想到什么就写什么。定一份完整的大纲对我来说太麻烦了，思来想去，还是先记下一些点点线线，免得以后真想写的时候，憋坏脑子也想不出下一步。

说到底，想一出是一出才比较符合我的性格。我也不知道这东西最后会被写成什么样，能写多久，又会写到哪里。或许我会把它发在 GitHub 上。有人在 GitHub 上写小说吗？

总之，作为一篇序，大概就是这些。

远方
